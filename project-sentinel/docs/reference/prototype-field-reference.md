# Project Sentinel prototype field reference

This reference describes fields shown in the illustrative prototype.

| Field | Purpose | Validation status |
|---|---|---|
| Service name | Identifies the monitored microservice | Illustrative |
| Environment | Identifies production, staging, or development | Illustrative |
| Owner or team | Identifies the responsible team | Illustrative |
| Repository | Links the service to its source repository | Proposed |
| Telemetry source | Identifies the logging, metrics, or tracing source | Illustrative |
| Service endpoint | Identifies a service or health endpoint | Illustrative |
| Latency threshold | Sets a response-time limit for alerting | Illustrative |
| Error-rate threshold | Sets a failed-request percentage limit | Illustrative |
| Evaluation window | Defines how long a condition is evaluated | Market-informed |
| Escalation delay | Defines when the next destination is notified | Market-informed |

All fields and supported values require confirmation before publication.
