# Monitoring data does not appear

## Problem

A newly added service appears in the inventory, but health or performance information is missing.

## Checks

1. Confirm that the correct environment was selected.
2. Confirm that the telemetry source is available.
3. Confirm that the service endpoint is correct and reachable.
4. Run the connection test again.
5. Verify that the service identity matches the telemetry configuration.
6. Confirm that the user or service account has the required permissions.
7. Review the connected logging or telemetry system for recent data.
8. Escalate with the service name, environment, endpoint, test result, and timestamp.

> The actual diagnostics and error messages require product validation.
