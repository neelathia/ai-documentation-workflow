# AI-assisted documentation workflow

## Purpose

Convert engineering input into source-grounded technical documentation through a controlled, reusable workflow.

## Workflow

1. Read the source and preserve source boundaries.
2. Extract feature facts, commands, files, interface labels, limitations, and unresolved questions.
3. Classify information as confirmed, missing, inferred, or conflicting.
4. Select the document type supported by the evidence.
5. Apply the appropriate reusable template.
6. Generate Markdown drafts.
7. Validate required content, exact technical strings, style rules, and unsupported additions.
8. Review the result against the human-authored reference output.
9. Require human approval before publication.

## Human and AI responsibilities

AI supports extraction, classification, drafting, and validation. Human reviewers remain responsible for source authority, technical accuracy, document-type selection, and publication approval.
