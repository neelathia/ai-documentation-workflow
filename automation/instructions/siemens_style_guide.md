# Siemens documentation style guide

## Voice and tense

- Use active voice.
- Use present tense.

## Company references

- Do not use "we" or "us" to refer to the company.

## Audience references

- Avoid the word "user."
- Refer to the specific role or audience when needed.

## Contractions

- Do not use contractions.

## File and path formatting

- Italicize filenames and pathnames.

## Interface formatting

- Use bold formatting for interface labels.

## Technical element formatting

- Use code formatting for commands, configuration elements, and code-related values.

## Headings

- Use sentence case for headings.
