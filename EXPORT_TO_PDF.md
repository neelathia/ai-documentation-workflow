# Export Markdown and HTML to PDF

## Markdown

Use a Markdown editor that supports PDF export, or use Pandoc:

```bash
pandoc input.md -o output.pdf
```

Review page breaks, tables, internal notes, and code blocks before submission.

## HTML

1. Open the HTML file in a browser.
2. Select **Print**.
3. Choose **Save as PDF**.
4. Enable background graphics when available.
5. Review the print preview before saving.

For the email submission, prioritize:

- `project-sentinel/docs/strategy/project-sentinel-documentation-strategy.md`
- `policy-enforcement/docs/policy-enforcement-overview.md`
